# Organización Sin Fines de Lucro - Aplicación Web

## Descripción
Aplicación web para gestionar donaciones, proyectos y voluntarios de una organización sin fines de lucro.

## Tecnologías utilizadas
- PHP (backend)
- MySQL (base de datos)
- HTML/CSS/JavaScript (frontend)
- Bootstrap (diseño responsivo)

## Funcionalidades
- Registro de proyectos
- Registro de donantes
- Gestión de donaciones
- Consultas avanzadas por proyecto

## Estado del proyecto
En desarrollo activo.
